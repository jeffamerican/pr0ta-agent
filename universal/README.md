# PR0TA skills

This host-neutral package is for tool-capable AI clients that can load Markdown
skill files or connect to a remote MCP server.

- Skill files: `skills/`
- Remote MCP configuration: `.mcp.json`
- MCP endpoint: `https://app.pr0ta.com/api/mcp/mcp`
- Plain-language setup guide: `https://www.protafilmmaker.com/downloads/skills/`

Compatibility depends on the AI application, not only the underlying model.
The application must support remote MCP tools or importing Markdown skill
files. Complete PR0TA sign-in through the host's normal OAuth flow.
